An agent's excuse for a missed deadline, from a tiny TypeScript program: it resumes from its last checkpoint to recover the lost work — only the checkpoint was taken before the deadline existed.

## Run it

```sh
node main.ts
```

The program writes one excuse (113 characters) to `/output/entry.txt`.
